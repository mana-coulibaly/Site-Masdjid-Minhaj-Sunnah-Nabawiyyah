## Livres PDF gratuits

Déposez ici vos fichiers `.pdf` pour qu’ils soient accessibles directement depuis le site, sans Google.

### Comment ajouter un livre

- Placez le fichier dans ce dossier: `docs/assets/books/`
- Ajoutez (ou modifiez) l’entrée correspondante dans `docs/assets/books/books.json`

### Fichier à éditer

- `docs/assets/books/books.json`

Chaque livre est un objet avec par exemple:

- `title`: titre du livre
- `author`: auteur
- `lang`: FR / AR / EN…
- `file`: chemin web du pdf (ex: `assets/books/mon-livre.pdf`)
- `description`: petite description (optionnel)

### Exemples de fichiers (fournis en démo)

- `assets/books/oussoul-ath-thalatha-fr.pdf`
- `assets/books/qawaid-al-arbaa-fr.pdf`
- `assets/books/oussoul-sitta-ar.pdf`
